# HeartDisease_prediction_using_ANN

This project uses an Artificial Neural Network (ANN) to predict the presence of heart disease in patients based on various medical attributes. It is built and trained in a Jupyter Notebook using Python and essential machine learning libraries.

Overview
Heart disease is one of the leading causes of death worldwide. Early prediction can significantly improve treatment outcomes. This notebook demonstrates how an ANN can be trained on a dataset to accurately classify whether a person is likely to have heart disease.

Heart_Disease_Prediction_using_ANN.ipynb: The main Jupyter Notebook containing data preprocessing, model building, training, evaluation, and visualization.
